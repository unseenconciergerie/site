# Site UNSEEN.

Le site public de UNSEEN., conciergerie privée de luxe à Paris.
En ligne sur https://unseenconciergerie.com

Ce dépôt ne contient **que le site**, tel qu'il est servi aux visiteurs.
Les outils internes, le CRM et les documents de travail sont ailleurs,
dans un dépôt privé.

## Comment c'est publié

Les fichiers de ce dépôt sont servis directement par GitHub Pages.
Toute modification poussée ici est en ligne une à deux minutes plus tard.

- `index.html` — la page principale
- `legal.html` — mentions légales
- `404.html` — page affichée sur une adresse inexistante
- `season.css` — **la couleur de saison**, le seul fichier à changer
  pour habiller le site autrement
- `anim.css` / `anim.js` — les animations
- `img/` — les photos, en AVIF avec repli WebP
- `CNAME` — l'adresse du site, à ne pas supprimer

Les images sont fabriquées par un script qui vit dans le dépôt privé,
à partir des photos d'origine en haute définition.
